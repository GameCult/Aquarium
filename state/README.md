# Persistent State

This directory is Aquarium's repo-local memory.

- `map.yaml` is the current client ownership map.
- `memory.json` is durable operating memory for future agents.
- `evidence.jsonl` stores compact lessons that should change future work.
- `scratch.md` is disposable context for the active slice.
- `life-agent-sdf-notes.md` preserves focused Life-body iteration notes.

When client ownership, visual grammar, persistent state, or Fensalir dependency
shape changes, update this directory with the same discipline used on code.

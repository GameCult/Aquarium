# Epiphany Aquarium Docs

This repo is the Epiphany client, not the Fensalir engine.

- `epiphany-agent-sdf-visual-language.md`: visual grammar for Self, role agents,
  and the cursor. Use this before changing Epiphany body shaders.
- `engine-client-boundary.md`: dependency direction between Epiphany Aquarium
  and Fensalir.
- `cult-runtime-surface.md`: typed CultCache documents and runtime state.

Persistent repo memory lives in `state/`.
